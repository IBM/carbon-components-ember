# Table

The AI Chat `Table` (exported as `Table`, not `DataTable` — see
[`DataTable`](../data-table.md) for the general-purpose Carbon data table) is
a sortable, filterable, paginated table for
[Carbon AI Chat](https://github.com/carbon-design-system/carbon-ai-chat),
with a built-in CSV download action. It's always internally-controlled —
sort/filter/page state live inside the component, matching upstream, which
has no equivalent change callbacks.

```gjs live preview
import { Table } from 'carbon-components-ember/components';
import { ThemeSupport } from 'docs-support';

const headers = [{ text: 'Name' }, { text: 'Status' }, { text: 'Owner' }];

const rows = [
  { cells: [{ text: 'invoice-001.pdf' }, { text: 'Complete' }, { text: 'Amanda' }] },
  { cells: [{ text: 'invoice-002.pdf' }, { text: 'Pending' }, { text: 'Bilal' }] },
  { cells: [{ text: 'invoice-003.pdf' }, { text: 'Complete' }, { text: 'Chidi' }] },
  { cells: [{ text: 'invoice-004.pdf' }, { text: 'Failed' }, { text: 'Amanda' }] },
  { cells: [{ text: 'invoice-005.pdf' }, { text: 'Complete' }, { text: 'Dara' }] },
  { cells: [{ text: 'invoice-006.pdf' }, { text: 'Pending' }, { text: 'Bilal' }] },
  { cells: [{ text: 'invoice-007.pdf' }, { text: 'Complete' }, { text: 'Chidi' }] },
];

<template>
  <ThemeSupport />
  <Table
    @tableTitle='Invoices'
    @tableDescription='Generated by the assistant'
    @headers={{headers}}
    @rows={{rows}}
    @filterPlaceholderText='Filter table'
    @downloadLabelText='Download as CSV'
    @previousPageText='Previous page'
    @nextPageText='Next page'
  />
</template>
```

## Loading state

```gjs live preview
import { Table } from 'carbon-components-ember/components';
import { ThemeSupport } from 'docs-support';

const headers = [{ text: 'Name' }, { text: 'Status' }];
const rows = [];

<template>
  <ThemeSupport />
  <Table @loading={{true}} @defaultPageSize={{3}} @headers={{headers}} @rows={{rows}} />
</template>
```
