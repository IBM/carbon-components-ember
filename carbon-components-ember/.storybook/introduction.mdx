# Carbon Components Ember

An Ember implementation of IBM's [Carbon Design System](https://carbondesignsystem.com),
kept in parity with [`@carbon/react`](https://react.carbondesignsystem.com).

## Installation

```sh
pnpm add carbon-components-ember @carbon/styles
```

### Compatibility

- **Ember:** tested against `ember-source` 7 (the current release), and in CI
  against the beta and alpha channels too.
- **Apps:** it's a v2 addon for strict-mode templates (`.gts` and `.gjs`).
  Loose-mode `.hbs` templates can't resolve its components by name
  (`<Carbon::TextInput>`). Embroider/Vite apps work as-is; classic ember-cli
  apps need `ember-auto-import` 2 and `ember-template-imports`.

Load Carbon's styles and the addon's own stylesheet once, in your app's
entry point:

```ts
import "@carbon/styles/css/styles.css";
import "carbon-components-ember/styles.css";
```

## Usage

Import components straight into your `.gts` templates:

```gts
import { Button } from "carbon-components-ember/components";

<template>
  <Button @type="primary">Save</Button>
</template>
```

Services are namespaced under `carbon.`:

```ts
import { service } from "@ember/service";

class MyComponent {
  @service("carbon.notifications") notifications;

  saved = () => this.notifications.success({ title: "Saved" });
}
```

The notifications service shows its toasts in a `ToastNotificationList`,
rendered once in the application template.

Every component page in the sidebar is generated from the component's own
Glint signature: the args table, blocks and element come straight from the
source, and each story doubles as a browser test. Stories follow Carbon
React's: the same pages, names and variants, and each story file lists any
React story it can't match yet.

## Use with AI agents

The package ships an [agent skill](https://agentskills.io) for coding agents:
how to use the components, how Carbon's React-based docs and designs carry
over to Ember, and these docs for the version your app has installed. With pnpm 12.11 or later, approve
it once with `pnpm approve carbon-components-ember`. The
[README](https://github.com/IBM/carbon-components-ember#use-with-ai-agents)
covers the requirements, and the steps for TanStack Intent, npm and Yarn.

[`carbon-components-ember-mcp`](https://github.com/IBM/carbon-components-ember/tree/main/carbon-components-ember-mcp#readme)
serves the same docs over MCP, and gives agents the skill's instructions when
they connect. Add it from your app's directory, for example in Claude Code:

```sh
claude mcp add carbon-components-ember -- npx -y carbon-components-ember-mcp
```
